# Security

Do not report a suspected vulnerability in a public issue, pull request, or
discussion.

- **Public repositories:** use **Report a vulnerability** on the repository's
  Security tab.
- **Private repositories:** contact the maintainer directly through the private
  channel you already use with them.

Include the affected version or component, impact, a minimal reproduction, and
any known mitigations. Do not include live credentials or private source code.

Security fixes are applied on a best-effort basis to the latest release and the
latest code on the default branch.
